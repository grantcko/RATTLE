# RATTLE Agent Notes

## API Gaps

When working with DaVinci Resolve scripting or any project API in this repo, record useful missing API capabilities as you discover them. If a task would be much cleaner with a direct API call but requires UI automation, AppleScript, XML editing, or another workaround, add a note to the RATTLE Notion project's API feature-request subpage.

Each note should include:

- the desired API capability
- the workaround that was required
- why the direct API would reduce risk or manual effort
- the concrete RATTLE task that exposed the gap

The goal is to keep a usable list that can eventually be submitted upstream to the API owner.
